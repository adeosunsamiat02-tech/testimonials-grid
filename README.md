# Testimonials Grid Section — Frontend Mentor

A responsive testimonials grid section solution to the [Frontend Mentor Challenge](https://www.frontendmentor.io/challenges/testimonials-grid-section-Nnw6J7Un7).

## 🔗 Live Demo
https://testimonials-grid-q0cc.onrender.com

## 📸 Overview
This project is a responsive testimonial grid that adapts from a single column on mobile to a 4-column asymmetric grid on desktop using Tailwind CSS Grid utilities like `col-span-2` and `row-span-2`.

## ✨ Features
- Fully responsive
- CSS Grid asymmetric layout
- Tailwind CSS for utility-first styling
- Semantic HTML5 markup

## 🛠️ Built With
- HTML5
- Tailwind CSS v3
- CSS Grid & Flexbox
